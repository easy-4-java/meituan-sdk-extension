## `meituan-sdk-extension` 覆盖审计

审计目标：`/Users/wandl/workspaces/workspace-github-easy-4-java/meituan-sdk-extension`，分支 `feature/3.0.x`，
基准提交 `22f99db82d5b6219a8fdfdcde4c86735a32cb29b`（叠加本次工作区修改），扩展版本
`3.0.x.20260730-SNAPSHOT`，官方 SDK 坐标 `com.sankuai.sjst:MtOpJavaSDK:1.0.20260831`。

审计口径：

- API 覆盖必须同时存在官方 `MtOpJavaSDK` Request、`MeituanRetailService` 强类型门面方法及其实现。

- 清单没有文档链接、接口路径或 `msgType` 时，不使用中文名称猜造协议。

## 剩余边界

- “次月扣款指令同步”“次月扣款查询”“取消连续包月通知”仍需要美团侧提供接口路径、参数定义或消息 `msgType` 后，才能实现并验证。
- 本次完成的是 SDK 出站 API 与入站消息协议层覆盖；具体消息触发的设备操作、团单核销和退款领域动作仍应在业务服务中分别实现并做联调验收。
- 对设备启动、团单核销、退款等有副作用的回调，业务服务必须在执行动作前持久化 `msgId` 并做幂等去重，同时按美团协议校验回调时间窗口；SDK 通用回调组件不替代这些业务保障。
- “已开通”是美团控制台权限状态，不等于生产环境已经完成真实调用或回调验收。
