- API 覆盖必须同时存在官方 `MtOpJavaSDK` Request、`MeituanStoreService` 强类型门面及实现，并按官方 `needAuth` 元数据选择调用路径。

## 剩余边界

- SDK 已覆盖四个出站 API 和一个入站消息的传输协议；真实开发者凭据、请求参数、门店数据以及消息回调地址仍需环境联调。
- 自定义 `MeituanRequestExecutor` 必须实现带 `tenantId` 的免授权调用重载；默认方法采用 fail-closed，防止静默忽略租户并误用开发者凭据。
- 回调业务服务必须在处理前持久化 `msgId` 并做幂等去重；审核结果入库、门店状态更新和失败补偿由接入应用负责。
- “已开通”是美团控制台权限状态，不等于生产环境已完成真实调用或回调验收。
